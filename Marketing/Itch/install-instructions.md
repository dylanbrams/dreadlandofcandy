## How to install and play

**Windows 10 or 11, 64-bit. Download is about 690 MB; it unpacks to about 960 MB.** There is no installer.

1. **Download** `ImaginaryComponent_TheDreadLandOfCandy.zip` from this page.
2. **Extract the whole ZIP** to a folder you can write to (Desktop, Documents or `C:\Games` are fine). Use *Extract All* in File Explorer, or 7-Zip. Don't run the game from inside the ZIP: it won't start.
3. **Open the extracted folder and double-click `MegaJam.exe`.** (The folder also contains `Engine` and `MegaJam` folders. Leave them where they are.)
4. Pick your lead (knight, mage, archer or barbarian) and start your first take.

The first launch can take a little longer while shaders and files load.

### Controls
Keyboard and mouse or a gamepad both work. Every screen can be used with a gamepad.

### If something goes wrong
- **Windows SmartScreen says "Windows protected your PC".** The build isn't code-signed. Click *More info*, then *Run anyway*.
- **Antivirus quarantines a file or the game closes at once.** Re-extract the ZIP, and if it keeps happening, add the folder as an exception.
- **A missing-DLL message.** Install the latest [Microsoft Visual C++ Redistributable (x64)](https://aka.ms/vs/17/release/vc_redist.x64.exe).
- **Black screen, crash or very low frame rate.** Update your graphics drivers and close other heavy programs. A GPU from the last several years is recommended.
- **Director's notes don't respond.** Typed notes go to an online AI service. Without an internet connection the game uses built-in notes and fallback directions, and is still fully playable.

### Uninstall
Delete the folder you extracted. The game keeps saves and logs in `%LOCALAPPDATA%\MegaJam`; delete that folder too to clear them.
