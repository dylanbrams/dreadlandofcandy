# Devlog working kit

Open `index.html` in a browser. Use the arrow keys or buttons; press N for speaker notes and F for fullscreen. The deck works offline. Edit `slides.js` to change text, notes and images; no build tools are needed. The script is in `SCRIPT.md`, and `EVIDENCE.md` holds timeline additions and source pointers. Claude can edit these plain text files directly.

This is a living checkpoint. After the next session, update the evidence, script and slides; replace the ending placeholder with verified outcomes. The existing Checkpoint1 charts and PowerPoint remain intact. Times in the old Gantt are estimates, not hours worked.

The asset comparison is in `assets/generation-comparison.jpg`, with provenance and important differences in `EVIDENCE.md`. `render_assets.py` and `make_comparison.py` document how the Blender renders and labeled card were made. The deck references existing images outside this folder, so keep it inside Devlog when moving or sharing it.
