## Known issues

- The game target builds as a unity build: two .cpp files with the same names in anonymous namespaces fail only there (the T16 package failed this way). `Scriptsuild.ps1 -Game` catches it in a few minutes.
- Nuisance state labels only show with `-debuglabels` (they drew in Development builds, which is what the jam ships).
- **Editor `-game` sometimes hangs at startup** (frame 0, right after a build or test run); twice today. Retrying works. Do not kill Unreal processes blindly: Dylan may have an editor open.
- **Smoke test timing:** pass `-timescale=4` with `-autoplay` (a real-time film does not fit 60 s); with typed notes against a server use `-RunSeconds 110`.
- **Bot answers CUT! at once:** autoplay reads the stale `StateEnteredAt` in the frame the prompt opens, so it skips its 1.5 s think. Harmless.
- Missing VO clips log a `LoadPackage: SkipPackage` warning per caption in packaged builds (T23 looks them up by path). Harmless; quieter via the asset registry if it matters.
