# Black Sugar UI fonts

Acquired 2026-11-15 from the Google Fonts repository. Static files were instantiated from the repository's variable TTFs with fontTools 4.44.3; the `wght` axis was fixed at 500 (Medium) or 600 (SemiBold). Names and OS/2 weight classes were set to match the fixed instance, then inspected with fontTools.

## Sources and licenses

- [Cinzel source TTF](https://github.com/google/fonts/blob/main/ofl/cinzel/Cinzel%5Bwght%5D.ttf) · [Cinzel OFL](https://github.com/google/fonts/blob/main/ofl/cinzel/OFL.txt) · upstream project [NDISCOVER/Cinzel](https://github.com/NDISCOVER/Cinzel)
