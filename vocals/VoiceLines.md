# Voice line candidates (villagers, heroes, opponents)

Written 2026-11-11 for ElevenLabs. Pick from these; nothing here is in `JamLines` yet. Ids are suggestions and match the `VO_<LineId>` convention.

Three things to know while sorting:

- These are riffs on famous game lines, reworded, not quotes. `Jokes.md` currently says "nothing is quoted from another game"; riffs keep that true, but they are a new flavour of joke for this game.
- `Jokes.md` says the hero never speaks. The hero section below breaks that, so it is its own pool: use it only if you lift the rule (or give the lines to the audition heroes instead).
- Villagers stay sincere. The reference is funny because they mean it.

Everything in the file is about 11,000 characters if you voiced all of it. Text only, no stage directions inside the lines, so nothing gets read aloud by accident.
